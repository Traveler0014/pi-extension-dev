# pi-extension-dev

pi 插件开发套件，两种用法：

## Install —— 获得插件开发技能

```bash
pi install https://github.com/Traveler0014/pi-extension-dev.git
```

安装后获得 `/skill:pi-extension-dev`（插件开发完整工作流：脚手架 → 设计 → 实现 → 测试 → 发布）。**不注册任何扩展**，零工具列表污染。

对话中说"帮我写个 pi 插件"时技能自动加载，或手动注入：

```
/skill:pi-extension-dev
```

## Fork —— 获得插件仓库脚手架

GitHub "Use this template"（或 fork），得到：

- `tools/example-plugin/` —— Tool + Command 完整模式示例（typebox schema、两层错误信号、lib.ts 分层、自检命令、vitest）
- `example-provider/` —— Provider 注册示例
- `scripts/update-docs.ts` + `release.sh` —— AST 文档生成与发布流程
- `AGENTS.md` —— 仓库开发/发布规则（设计规范在 skill 中，按需加载）

Fork 后：把你的插件加入根 `package.json` 的 `pi.extensions`，按 `AGENTS.md` 流程开发发布。
